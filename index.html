Comandos Git Principais

  • git init - Inicializa um repositório local.
  • git add . - Adiciona as alterações à área de staging.
  • git commit -m "mensagem" - Registra um ponto na história do projeto.
  • git branch feature - Cria uma nova branch de funcionalidade.
  • git checkout feature - Alterna para a branch especificada.
  • git merge feature - Mescla as alterações da branch para a atual.
  • git log --oneline - Exibe o histórico de commits simplificado.
